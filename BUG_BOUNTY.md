# Bug Bounty Program

## Overview
LayerZero V2 bug bounty program for the omnichain interoperability protocol.

## Rewards
| Severity | Reward |
|----------|--------|
| Critical | $50,000 - $1,000,000 |
| High | $10,000 - $50,000 |
| Medium | $2,000 - $10,000 |
| Low | $500 - $2,000 |

## In Scope
- LayerZero protocol smart contracts
- Endpoint contracts
- Message library vulnerabilities
- DVN (Decentralized Verifier Network) issues
- Executor contract vulnerabilities
- OFT (Omnichain Fungible Token) contracts
- ONFT (Omnichain Non-Fungible Token) contracts

## Out of Scope
- Frontend UI issues
- Third-party integrations
- Social engineering
- DDoS

## Reporting
Submit to: bounty@layerzero.foundation
PGP Key: Available at https://layerzero.foundation/security

Include:
- Vulnerability description
- Impact assessment
- Proof of concept
- Suggested fix

## Response Timeline
- Acknowledgment: 24h
- Initial triage: 72h
- Fix development: Based on severity
- Bounty payment: Within 30 days of fix
